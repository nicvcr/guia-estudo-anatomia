# Guia de Estudo & Simulado — Anatomia do Aparelho Locomotor (2º Período)

Guia interativo de estudo para prova de **Anatomia do Aparelho Locomotor (2º período)**, contendo resumos didáticos, diagramas visuais em SVG, tabelas comparativas, 16 flashcards de pegadinhas e simulado com 30 questões de múltipla escolha comentadas.

🔗 **Acesse online (GitHub Pages):** https://nicvcr.github.io/guia-estudo-anatomia/

## Conteúdo
1. **Crescimento e Desenvolvimento do Sistema Esquelético**
2. **Tecido Muscular, Contração, Energia e Tipos de Fibras**
3. **Controle Neural do Movimento**
4. **Funções Musculares no Movimento Humano**
5. **Fáscias: Organização, Função e Relevância para o Movimento**
6. **⚡ Revisão Turbo (16 Flashcards)** e **📝 Simulado Interativo (30 Questões)**
